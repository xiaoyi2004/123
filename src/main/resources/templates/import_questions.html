支持格式说明

📄 文本文件（.txt / .docx）

每道题用空行分隔，支持以下字段（可使用冒号分隔）：

题型：单选题
科目：Java
知识点：面向对象
难度：3
题干：Java中哪个关键字用于定义类？
A. class
B. public
C. static
D. void
答案：A
解析：class用于声明类。

自动识别题型（单选、多选、判断、填空、简答、分析、编程），若未指定则自动检测。

📊 Excel文件（.xlsx）

第一行为标题行，从第二行开始每行一道题，列顺序为：

列字段必填示例
1题型否单选题 / 多选题 / 判断题 / 填空题 / 简答题 / 分析题 / 编程题
2科目否Java
3知识点否面向对象
4难度否3
5题干是Java中哪个关键字用于定义类？
6选项A选择题需提供class
7选项B同上public
8选项C同上static
9选项D同上void
10选项E多选用（留空）
11答案是A 或 A,B,C
12解析否class用于声明类。
